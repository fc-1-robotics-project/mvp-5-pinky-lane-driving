# Pinky Lane Driving

ROS 2 Jazzy · YOLO26 segmentation 기반 2차선 우측통행 주행 프로젝트.

## 현재 상태

설계 및 구현 계획을 등록한 단계입니다. 주행 코드는 아직 구현하거나 실제 로봇에 배포하지 않았습니다.

## 목표

- 현재 우측 차로의 중심 추종
- 횡단보도 일시정지 및 재출발
- 장애물 정지 및 제거 확인 후 재출발 (우회는 제외)

## 설계와 진행 기록

- [설계·알고리즘·안전 조건 — #1](../../issues/1)
- [기능별 구현·커밋·검증·SSH 배포 계획 — #2](../../issues/2)

구현 순서는 경로 추출 → Pure Pursuit 제어 → 행동 상태기계 → ROS/안전 → 배포입니다.
기능별로 커밋을 나누고 변경 이유, 이슈 번호, 실제 테스트 결과와 미검증 항목을 기록합니다.

## 기존 프로젝트와의 관계

기존 pinky_pro 저장소를 재사용하거나 원격 주소를 교체하지 않습니다.
새 주행 패키지를 독립적으로 관리하고 로컬 /home/seunghoon/ros/pinky_pro에서 연동 검증합니다.
기존 변경 파일을 보존하며, 검증 후 실제 로봇의 환경과 경로를 확인하여 SSH로 선택 배포합니다.

## 데이터 및 안전

모델, 영상, 학습 데이터, 비밀번호, 인증키는 커밋하지 않습니다.
두 영상에서의 인식 성공은 실물 주행 안전성이나 독립 데이터 정확도의 증명이 아닙니다.
기본 모터 비활성 검증, 로봇 측 watchdog, 낙상 방지 및 물리 비상정지 확보 후 저속 실물 시험을 진행합니다.
